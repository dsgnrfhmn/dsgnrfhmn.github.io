# dsgnrfhmn.github.io

Portfolio page, built on [dis-system](https://github.com/dsgnrfhmn/dis-system) (git submodule).

```sh
git clone --recurse-submodules git@github.com:dsgnrfhmn/dsgnrfhmn.github.io.git
python -m http.server 8000   # open http://localhost:8000
```

Update the design system: `git submodule update --remote dis-system`, then commit.
